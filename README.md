# Экзамен ГИБДД — Маршрут 2

Веб-приложение для подготовки к экзамену ГИБДД на маршруте №2 в Красноярске.

Позволяет:

* Просматривать экзаменационный маршрут на карте
* Добавлять сложные точки маршрута
* Сохранять рекомендации инструктора
* Прикреплять фотографии перекрёстков, знаков и дорожной разметки
* Вести собственную базу проблемных мест
* Быстро повторять маршрут перед экзаменом
* Просматривать подробную карточку каждой точки

---

# Возможности

## Карта маршрута

На карте отображается экзаменационный маршрут.

Маршрут автоматически строится по дорогам через OSRM и отображается поверх OpenStreetMap.

---

## Точки маршрута

Пользователь может кликнуть в любое место карты и создать точку.

Для каждой точки можно сохранить:

* Название
* Тип манёвра
* Правильное выполнение
* Типичные ошибки
* Описание
* Сложность (1–5)
* Фотографии правильного выполнения
* Фотографии места

---

## Просмотр точки

При клике на маркер на карте или на элемент в списке открывается подробная карточка точки.

Карточка содержит:

* Название
* Тип манёвра
* Сложность
* Координаты
* Правильное выполнение
* Типичные ошибки
* Описание
* Все прикреплённые фотографии

---

## Режим повторения

Позволяет последовательно просматривать все точки маршрута.

Полезно перед практическим экзаменом или занятием с инструктором.

# Запуск проекта

## Требования

* Node.js 20+
* npm 10+

Проверить версии:

```bash
node -v
npm -v
```

---

## Установка

Создать проект:

```bash
npm install
```

Установить зависимости:

```bash
npm install leaflet react-leaflet
npm install -D @types/leaflet
```

---

## Запуск

Запуск режима разработки:

```bash
npm run dev
```

После запуска приложение будет доступно по адресу:

```txt
http://localhost:5173
```

---

## Production сборка

Создание production-сборки:

```bash
npm run build
```

Предпросмотр production-сборки:

```bash
npm run preview
```

---

# Хранение данных

Все данные сохраняются локально в браузере через LocalStorage.

Никакие данные не отправляются на сервер.

После очистки LocalStorage браузера данные будут удалены.
